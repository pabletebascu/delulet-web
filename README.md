# Delulet · Web

Web de Delulet: detalles personalizados hechos a mano con telas y bordados.

## Estructura

- `index.html`: la página (inicio, quiénes somos, bodas y eventos, catálogo, contacto)
- `css/estilos.css`: colores, letras y diseño
- `js/main.js`: menú del móvil y formulario
- `img/`: logo y fotos de producto
